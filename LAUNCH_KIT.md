## One-line Description

Walrus Decentralized Image Bed is a production-ready Walrus file sharing app that lets users upload images and files from the browser with a Sui wallet and verify the developer identity on chain.

## Short Description

Walrus Decentralized Image Bed is a consumer-facing upload and file sharing app built with Next.js, Sui dApp Kit, and the official `@mysten/walrus` SDK. It supports Mainnet and Testnet, browser uploads through Walrus Upload Relay, direct file retrieval, image preview, local upload history, and an on-chain Sui Registry package that links the app to the developer wallet and GitHub repo.

## Long Description

I built Walrus Decentralized Image Bed as a practical, end-user-friendly Walrus application instead of a protocol-only demo. The app gives users a clean browser flow for uploading images and common files with a Sui wallet, returning a direct file link, preview, and storage proof details. It supports both Mainnet and Testnet and is deployed live on Vercel.

To make the project easy to verify, I also published a lightweight Sui Registry package that records the app identity on chain. That package links the project name, developer wallet, website, and GitHub repository, so anyone reviewing the project can verify that the same developer wallet is behind the live app and the chain identity.

## What Makes This Project Worth Looking At

- real end-user upload experience, not only SDK scaffolding
- wallet-signed Walrus register / certify flow
- support for both image and general file uploads
- direct retrieval links that work with Walrus blob and quilt-backed files
- on-chain developer identity package for credibility and discoverability
- live deployment plus open-source codebase
